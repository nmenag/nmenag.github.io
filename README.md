# nmenag

This is the source code for my personal landing page and mobile app portfolio hosted at [nmenag.github.io](https://nmenag.github.io).

## Design Highlights

- **Typography**: Geometric headings using _Outfit_ combined with a readable, tech-focused body using _Inter_.
- **Palette**: A high-end dark slate neutral palette combined with positive-growth emerald green tones, matching the Habit Money brand identity.
- **Aesthetic**: Premium cards, clean border rules, and blurred ambient radial-glow backdrops for a sleek, modern visual presentation.
- **Local-first focus**: Highly matches the development philosophy of simple, fast, and privacy-respecting digital tools.
